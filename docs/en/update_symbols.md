# Export YAML Artifacts to `kphdyn.xml`

[Back to README](../../README.md)

`update_symbols.py` is a YAML-to-XML exporter.

## Usage

Export YAML artifacts:

```bash
uv run update_symbols.py [-xml="kphdyn.xml"] [-symboldir="path/to/symbols"] [-configyaml="config.yaml"]
```

The exporter reads the YAML artifacts generated by [`dump_symbols.py`](dump_symbols.md) and updates the corresponding entries in `kphdyn.xml`.

Synchronize unmanaged PE files found under the symbol directory into the XML:

```bash
uv run update_symbols.py [-xml="kphdyn.xml"] [-symboldir="path/to/symbols"] -syncfile
```

`-syncfile` is a separate mode and exits after synchronizing file entries. Run the exporter without `-syncfile` afterward to export symbol values.

If a symbol YAML is missing or unresolved, `update_symbols.py` exports:

- `0xffff` for `uint16`.
- `0xffffffff` for `uint32`.
